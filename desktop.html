01 · USER PROBLEM // 用户痛点
传统 AI 图像编辑工具依赖单一模型“一次性直接生成”，生成结果具有高方差与幻觉黑盒特征。用户经常遇到背景伪影或虚构物体，被迫反复修改 Prompt 手工重试，调试成本极高。
02 · PRODUCT SOLUTION // 产品方案
设计 Multi-Candidate 智能体竞争与自我纠错闭环。将生成过程解构为“并发候选生成 ➔ 幻觉风险评估 ➔ 智能打分路由”，由 Agent 自动过滤劣质结果并决策出最优交付物。
03 · AI ARCHITECTURE // 技术底座
• 感知层：GroundingDINO 开放词表对齐 + SAM 像素分割（9×9膨胀核）
• 执行层：SD1.5 多种子并发 + LaMa 频域补全 + OpenCV Telea 兜底
• 决策层：双向 IoU 差异化幻觉检测 + 调和均值综合评分 (Harmonic Mean)

海量互联网新闻存在信息冗余大、时序跨度长、特征高度稀疏等痛点。传统统计学分类算法准确度不足且维护成本高，难以应对高吞吐的内容审核与推荐打标需求。
02 · PRODUCT SOLUTION // 产品方案
搭建自动化数据清洗与模型横评 Pipeline。通过工程化对比 MLP、CNN、RNN、LSTM 与 CNN+LSTM 混合模型，选定兼具空间局部特征提取与时序长记忆的最优落地模型。
